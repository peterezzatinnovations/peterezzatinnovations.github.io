# Peter Ezzat Innovations — V2

موقع عربي ثابت باتجاه RTL. النشر المعتمد هو **GitHub Pages من فرع main ومجلد / (root)**، دون خطوة بناء أو تثبيت حزم.

## رفع التحديث يدويًا

استبدل الملفات التالية في جذر المستودع:

- `index.html`
- `app.js`
- `style.css`
- `package.json`
- `README.md`

أضف:

- `.nojekyll` في جذر المستودع.
- `public/images/social-preview.jpg` في المسار نفسه تمامًا.

احتفظ بكل الصور والخطوط الموجودة في `public/images/` و`public/fonts/` دون نقل أو إعادة تسمية. لا ترفع ملفات المصدر الأصلية الكبيرة أو مجلد `dist/` أو أدوات الاختبار؛ لا يحتاج النشر إليها.

في **Settings → Pages** اختر **Deploy from a branch** ثم **main / (root)**. لا تستخدم سير عمل مخصصًا ينشر `dist/` مع هذه الاستراتيجية. تمت إزالة سير العمل المحلي القديم؛ عند مراجعة المستودع العام لم يكن هناك ملف `.github/workflows/pages.yml` أو مجلد `tools/` أصلًا.

## لماذا تغير إعداد البناء؟

كانت نسخة `package.json` في GitHub تشير إلى `tools/build.mjs` و`tools/serve.mjs`، بينما تلك الملفات غير موجودة في المستودع (HTTP 404 عند التحقق). الموقع نفسه لا يحتاج بناء. أزيلت مراجع التشغيل المفقودة؛ الأمر الوحيد الاختياري هو:

```sh
npm run check
```

وهو يتحقق من صياغة JavaScript باستخدام Node.js، ولا يحتاج تثبيت حزم أو مجلد tools. النشر من فرع الجذر لا يعتمد حتى على Node.js.

للمعاينة المحلية في مساحة العمل التي تحتوي الأدوات: `node tools/serve.mjs` ثم افتح `http://127.0.0.1:4173/`. يمكن أيضًا فتح `index.html` مباشرة لمعاينة أساسية.

## صورة المشاركة

الرابط النهائي بعد الرفع:

https://peterezzatinnovations.github.io/public/images/social-preview.jpg

الصورة JPG بأبعاد 1200 × 630، مركبة من صورة الاستقبال الأصلية والشعار الأصلي والخط المحلي. افتح الرابط مباشرة بعد رفعها وتأكد من ظهورها، ثم تحقق من وجود الرابط نفسه في `og:image` و`twitter:image` بمصدر الصفحة المنشورة. معاينات واتساب وفيسبوك قد تبقى مخزنة مؤقتًا؛ لا يوجد ضمان لتحديثها فورًا.

## المعرض

24 صورة، دون فلاتر، بعنوان «من أعمالنا». العرض تدريجي: 6 ثم 12 ثم 18 ثم 24. عارض الصور يتصفح المجموعة الكاملة من 24 صورة، حتى لو لم تُكشف كل الصور المصغرة بعد. لكل صورة وصف وحالة دقيقة؛ اكتمال صورة جدار التلفاز لا يزال غير مؤكد.

الصور المصغرة تستخدم نسخ WebP بعرض 480/960 مع التحميل المؤجل، والصور الأكبر مخصصة لعارض الصور. الصور الأصلية محفوظة دون تعديل. لتحديث المعرض، عدّل `projects` في `app.js` وأبقِ مسارات الأصول تحت `public/`.
